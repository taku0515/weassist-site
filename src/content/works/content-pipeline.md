## 課題

情報発信が重要と分かっていても、記事の執筆・投稿・SNS展開を毎日続けるのは大きな負担です。継続できずに止まってしまうブログやSNSアカウントは少なくありません。

## 解決アプローチ

ニュース収集 → 記事草稿の生成 → 校正 → ブログ投稿 → SNS用テキスト作成という一連の流れを、ローカルLLMを中心としたパイプラインで自動化しました。

- 記事生成: ローカルLLM（Ollama）による下書き作成
- 投稿: WordPress REST API 経由で自動投稿
- 安全弁: 「要確認」フラグ付きの記事は自動公開せず下書きに留める設計
- Windowsタスクスケジューラによる毎朝の自動実行

## ポイント

この仕組みは実際に当社ブログ「KENGO's MEMO」をほぼ毎日更新し続けており、**デモではなく実運用中**であることが最大の実績です。人が最終確認を挟める設計にすることで、自動化と品質管理を両立しています。
